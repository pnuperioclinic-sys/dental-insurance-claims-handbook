## 건강보험청구 실무 핸드북

### 구성

- **1차 자료 링크** — 치협 급여기준 책자, 심평원 급여기준 조회, 요양기관업무포털, 요양기관정보마당
- **4주 교육 커리큘럼** — 주차별 주제와 실습 과제
- **청구 업무 흐름** — 덴트웹 기준 6단계
- **항목별 급여기준** — 치석제거 / 광중합형 복합레진 / 임플란트 / 틀니 / 근관치료
- **덴트웹 실무 적용** — 매일 지키는 4대 규칙, 상황별 입력법, 지혈제 코드표, 복사용 툴팁 문구 6종
- **삭감 방지 체크리스트** — 11항목 (체크 상태는 각 브라우저에 저장)
- **심사결과 대응** — 보완청구 / 재심사조정청구 / 이의신청 기한
- **직원 확인 퀴즈** — 12문항

### 주의

급여기준·심사지침·수가는 보건복지부 고시로 수시 개정됩니다.
실제 청구 판단은 반드시 대한치과의사협회 『치과건강보험 요양급여비용 및 급여기준』 최신판과
건강보험심사평가원 급여기준 조회시스템 원문으로 확인하십시오.

## 압도적 1등 병원 기획 노트

이정숙 《압도적 1등을 만드는 병원 기획의 정석》(해뜰서가, 2026)을 치과 직원용으로 간추린 요약본입니다.

- **챕터별 핵심** — 브랜딩 / 신환 유입 / 방문 경험 / 직원·조직 / 성과 관리
- **바로 쓰는 도구 4가지** — 4W 설명 구조, AIDA 유입 흐름, VOC 우선순위, STP
- **역할별 적용** — 데스크 / 진료실 / 상담·실장 / 원장
- **이번 주 체크리스트** — 6항목

원문 전체가 아니라 공개된 서평들을 교차 확인해 재구성한 요약이며,
'우리 병원에서는' 항목은 책 원문이 아닌 현장 적용 제안입니다.
